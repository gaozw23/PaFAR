# Local clinical data

PhysioNet/CinC 2019 raw data are not included in this repository.

Authorized users should place the two training sets at:

- `data/physionet2019/raw/training_setA`
- `data/physionet2019/raw/training_setB`

Do not commit patient files, patient identifiers, processed data, feature caches, fitted objects, or derived patient-level datasets. Obtain the data and official evaluation resources from their authorized upstream sources and follow the applicable access and redistribution terms.
